# Satellite Ground Station Dashboard

Live tracking of NOAA weather satellites and ISS.

## Features
- Real-time satellite positions
- 2D map + 3D globe view
- Pass predictions
- Visibility calculations
- Dynamic satellite footprint

## Tech Stack
- Python (Flask)
- Skyfield
- JavaScript (Leaflet + Three.js)
- Render deployment
